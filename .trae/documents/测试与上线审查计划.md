## 二、执行策略

1. **并行执行**：阶段 A-H 无强依赖，可并行
2. **分模块派发**：静态扫描、HTTP 测试、安全审查可独立进行
3. **环境降级**：沙箱无 Redis/MySQL，HTTP 测试采用 file session 驱动
4. **报告汇总**：最后生成统一测试报告

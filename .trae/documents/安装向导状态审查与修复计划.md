## 二、当前状态分析

### 2.1 安装向导工作流（[app/command/Install.php](file:///workspace/app/command/Install.php)）

```
1. collectConfig()   交互式收集 DB/Redis/SMTP/Pay/Admin 配置

5. warmupCache()     预热 Redis：网盘源列表 + 敏感词库
```

### 2.2 发现的 Bug

**位置**：[app/command/Install.php](file:///workspace/app/command/Install.php#L337) `warmupCache()` 方法

**问题代码**：
```php
$stmt = $this->pdo->query('SELECT id, code, name FROM pan_sources WHERE status = 1 ORDER BY id');
```

**实际表结构**（[database/install.sql](file:///workspace/database/install.sql#L128-L144)）：
```sql
CREATE TABLE `pan_sources` (
  ...
  `enabled` TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '1启用 0禁用',
  ...
  -- 注意：没有 status 字段！
)
```

**模型层佐证**（[app/common/model/PanSource.php](file:///workspace/app/common/model/PanSource.php)）：
- 第 24 行：`'enabled' => 'int'`（类型转换字段）
- 第 49 行：`return $query->where('enabled', 1);`（scope 查询也用 `enabled`）

**影响**：
- 执行 `php think install` 时，"预热 Redis 缓存"步骤会抛出 `SQLSTATE[42S22]: Column not found: 1054 Unknown column 'status' in 'where clause'`
- 由于 `warmupCache()` 被 try-catch 包裹，不会中断安装流程，会输出 `[!] Redis 缓存预热失败: ...`
- **直接后果**：网盘源列表不会被缓存到 Redis（`pansou:pan:sources` key 缺失），可能导致前台首页/搜索页的网盘源筛选器加载变慢或异常
- 敏感词库预热 SQL（第 345 行）字段正确，不受影响

### 2.3 不需要修复的部分

- `sensitive_words` 表查询（第 345 行）字段正确：`word`、`replace`、`status` 均存在 ✅
- `admin_users` 表的 `setupAdmin()` 字段正确 ✅

## 三、修复方案

### 修复 1：修正 `warmupCache()` 中 `pan_sources` 查询字段

**文件**：[app/command/Install.php](file:///workspace/app/command/Install.php)

**变更**：第 337 行

```php
// 修复前
$stmt = $this->pdo->query('SELECT id, code, name FROM pan_sources WHERE status = 1 ORDER BY id');

// 修复后
$stmt = $this->pdo->query('SELECT id, code, name FROM pan_sources WHERE enabled = 1 ORDER BY sort, id');
```

**理由**：
1. `pan_sources` 表实际字段是 `enabled`（见 DDL），不是 `status`
2. 顺便补上 `ORDER BY sort, id`，与 [PanSource.php](file:///workspace/app/common/model/PanSource.php#L49) 中 scope 的排序逻辑保持一致（`idx_enabled_sort` 索引也按 `enabled, sort` 建立），确保缓存的网盘源顺序与前台展示一致

## 二、执行策略

1. **并行执行**：阶段 A-K 之间无强依赖，可并行修复
2. **分模块派发**：每个阶段派发给独立子代理执行
3. **统一验证**：最后统一执行 PHP 语法检查 + 模板渲染检查
4. **不破坏现有功能**：保留 ThinkPHP 模板变量/循环/JS 业务逻辑

## 三、验证标准

- PHP 语法检查：`find app extend -name "*.php" -exec php -l {} \;`
- 路由配置检查：`php think route:list`
- 配置文件加载：`php think config:check`
- 模板渲染：访问首页/搜索/详情/登录/注册等关键页面 HTTP 200

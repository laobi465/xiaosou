### 阶段 B：Bug 修复（联调前置）

#### B1【高】后台登录表单未接 AJAX
- **文件**：`app/admin/view/publics/login.html`
- **问题**：`<form action="/admin/login" method="post">` 无 `data-action="ajax-form"`，且页面未引入 `admin.js`，提交后直接显示 JSON
- **修复**：
  1. 表单添加 `data-action="ajax-form"` 属性
  2. 页面底部引入 `<script src="__JS__/admin.js"></script>`
  3. 后端 `Publics::login()` 的 POST 分支已返回 JSON（`$this->success(['url'=>'/admin'])`），无需改动
- **验证**：提交登录 → toast 提示"登录成功" → 跳转 `/admin`

#### B2【中】前台布局不反映登录状态
- **文件**：`app/index/view/layout/main.html` + 前台各控制器
- **问题**：导航栏硬编码"登录/注册"，已登录用户无法看到"退出"
- **修复**：
  1. 在 `BaseController`（前台基类）中向所有视图共享 `$userId`/`$userNickname`（从 Session 读取，未登录则为 null）
  2. 布局模板用 `{if condition="$userId"}` 切换：已登录显示"个人中心 / 退出"，未登录显示"登录 / 注册"
- **验证**：未登录显示"登录/注册"；登录后显示"退出"

#### B3【低】搜索筛选值不回填
- **文件**：`app/index/controller/Search.php` + `app/index/view/search/index.html`
- **问题**：`size`/`time` 筛选值未传递到视图，输入框始终为空
- **修复**：
  1. 控制器 `view()` 调用增加 `'size' => $size, 'time' => $time`
  2. 视图 `<input name="size" value="{$size}">`、`<input name="time" value="{$time}">`
- **验证**：设置筛选提交后，输入框回显当前值

#### B4【低】资源类型枚举不一致
- **文件**：`app/index/view/index/index.html`
- **问题**：首页 `{switch}` 缺少 case 7（其他），靠 default 兜底
- **修复**：与搜索页/提交页统一，补充 `{case 7}其他{/case}`（可选，当前 default 已覆盖）
- **验证**：类型 7 资源显示"其他"

#### B5【低】VisitorLog 中间件未挂载
- **文件**：`route/index.php`
- **问题**：访问统计中间件已实现但未注册
- **修复**：在路由文件中为前台路由组添加 `->middleware(\app\index\middleware\VisitorLog::class)`
- **验证**：访问页面后 Redis 中出现访问日志记录

#### B6【低】Resource::report() 死代码清理
- **文件**：`app/index/controller/Resource.php`
- **问题**：`report()` 方法与 `Ajax::reportResource` 重复，路由指向后者
- **修复**：删除 `Resource::report()` 方法（保留 `Ajax::reportResource`）
- **验证**：举报功能正常（`/ajax/report/:id` 路由不变）

## 三、执行顺序与优先级

```
阶段 A（环境准备）→ 阶段 B（Bug 修复）→ 阶段 C（前台联调）
                                    → 阶段 D（后台联调）→ 阶段 E（接口验证）
                                    → 阶段 F（边界场景）→ 阶段 G（收尾）
```

**关键路径**：A → B1（后台登录修复）→ B2（前台登录态）→ C1（游客链路）→ C3（登录链路）→ D1（后台登录）→ D3（资源 CRUD）

## 四、风险与依赖

| 风险 | 影响 | 缓解 |
|------|------|------|
| 沙箱无 MySQL/Redis | 无法验证数据流 | 临时切换 file 驱动验证链路，或安装 MySQL/Redis |
| SMTP 配置为空 | 验证码邮件无法发送 | 配置测试 SMTP 或查看日志确认发送逻辑 |
| 彩虹易支付密钥为空 | 支付流程无法实测 | 验证订单创建逻辑，支付回调用 curl 模拟 |
| 爬虫 Cookie 池缺失 | 蓝奏云等采集无法实测 | 验证采集任务入队逻辑，实际采集待部署后验证 |

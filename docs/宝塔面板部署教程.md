## 一、环境准备

### 1.1 安装宝塔面板

如尚未安装宝塔面板，执行以下命令：

**CentOS/RedHat：**
```bash
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec
```

**Ubuntu/Debian：**
```bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
```

安装完成后，记录面板地址、账号、密码，登录宝塔面板。

### 1.2 安装 LNMP 环境

在宝塔面板首页，选择 **LNMP（推荐）** 安装：

| 组件 | 版本要求 | 推荐 |
|------|----------|------|
| Nginx | >= 1.20 | 1.24 |
| MySQL | >= 8.0 | 8.0 |
| PHP | >= 8.2 | 8.2 |
| Redis | >= 6.0 | 7.0 |

> **注意**：MySQL 必须选择 8.0 版本（需 FULLTEXT ngram 中文分词支持）。

### 1.3 安装 PHP 扩展

进入 **软件商店 → PHP 8.2 → 设置 → 安装扩展**，确保以下扩展已安装：

- `fileinfo`（必装）
- `redis`（必装）
- `pdo_mysql`（默认已装）
- `openssl`（默认已装）
- `mbstring`（默认已装）
- `bcmath`（推荐，支付金额计算）
- `gmp`（可选）

### 1.4 禁用 PHP 危险函数

进入 **PHP 8.2 → 设置 → 禁用函数**，删除以下函数（think-queue 需要）：

- `proc_open`
- `proc_get_status`
- `shell_exec`
- `exec`

> 保留 `system`、`passthru` 等其他危险函数的禁用。

## 二、配置 MySQL

### 2.1 修改 MySQL 配置（关键）

MySQL 8.0 默认 `ngram_token_size=2`，但需确认配置。进入 **MySQL 8.0 → 设置 → 配置修改**，在 `[mysqld]` 段添加：

```ini
[mysqld]
# 中文全文检索 ngram 分词
ngram_token_size=2
innodb_ft_min_token_size=2

# 字符集
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci

# 性能优化（按服务器配置调整）
innodb_buffer_pool_size=1G
max_connections=200
innodb_log_file_size=256M
```

修改后重启 MySQL。

### 2.2 创建数据库

进入 **数据库 → 添加数据库**：

| 项目 | 值 |
|------|-----|
| 数据库名 | `pansou` |
| 用户名 | `pansou` |
| 密码 | （生成强密码并记录） |
| 访问权限 | 本地服务器 |
| 字符集 | `utf8mb4` |

## 四、部署项目

### 4.1 添加站点

进入 **网站 → 添加站点**：

| 项目 | 值 |
|------|-----|
| 域名 | `your-domain.com`（替换为你的域名） |
| 根目录 | `/www/wwwroot/your-domain.com` |
| PHP 版本 | `PHP-8.2` |
| 数据库 | 不创建（已在 2.2 创建） |
| FTP | 不创建 |

### 4.2 上传项目代码

#### 方式一：Git 克隆（推荐）

通过宝塔终端（**终端** 菜单）：

```bash
cd /www/wwwroot/your-domain.com
# 清空默认文件
rm -rf ./*
# 克隆项目
git clone https://github.com/laobi465/xiaosou.git .
```

#### 方式二：上传压缩包

1. 从 GitHub 下载源码压缩包
2. 进入 **文件 → 站点目录**，上传并解压

### 4.3 安装 Composer 依赖

宝塔终端执行：

```bash
cd /www/wwwroot/your-domain.com
# 安装 Composer（如未安装）
curl -sS https://getcomposer.org/installer | php
mv composer.phar /usr/local/bin/composer

# 安装依赖
composer install --no-dev --optimize-autoloader
```

### 4.4 设置目录权限

宝塔终端执行：

```bash
cd /www/wwwroot/your-domain.com
chown -R www:www .
chmod -R 755 .
chmod -R 775 runtime
chmod -R 775 public
```

### 4.5 设置运行目录

进入 **网站 → 站点设置 → 网站目录**：

| 项目 | 值 |
|------|-----|
| 运行目录 | `/public` |

保存后，点击 **保存**。

### 4.6 安装前预检（推荐）

执行安装前，建议先手动检查环境是否就绪，避免安装中途失败。

**检查 PHP 版本与扩展：**

```bash
php -v
# 期望：PHP 8.2.x

php -m | grep -E 'pdo_mysql|redis|mbstring|openssl|bcmath|fileinfo'
# 期望输出：bcmath / fileinfo / mbstring / openssl / pdo_mysql / redis
```

**检查 MySQL ngram 配置：**

```bash
mysql -uroot -p -e "SHOW VARIABLES LIKE 'ngram_token_size';"
# 期望：2
```

若返回非 2，需回到 [2.1 修改 MySQL 配置](#21-修改-mysql-配置关键) 修改后重启 MySQL。

**检查 Redis 连通性：**

```bash
redis-cli -a your-redis-password ping
# 期望：PONG
```

**检查 Composer：**

```bash
composer --version
# 期望：Composer version 2.x
```

> 预检全部通过后再执行下一步安装向导，安装向导本身也会在写 .env 前自动预检 MySQL/Redis 连接。

### 4.7 执行安装（Web 向导推荐 / CLI 备选）

#### 推荐：Web 安装向导

浏览器访问 `http://your-domain.com/install`，按向导完成 5 步：

1. **环境检测**：自动检测 PHP 版本与扩展、MySQL 连通性、Redis 连通性
2. **数据库配置**：填写主机/端口/账号/密码，实时测试连接
3. **Redis 配置**：填写 Redis 连接参数，可跳过（跳过则使用文件缓存）
4. **邮件/支付/管理员配置**：SMTP 与支付可留空跳过，安装后登录后台 `/admin → 系统配置` 在线补充；设置管理员账号密码
5. **执行安装**：自动写 `.env` → 建库建表 → 导入种子数据 → 创建管理员 → 预热缓存 → 安装后自检

安装完成后，系统基于 `install.lock` 文件自动禁用 `/install` 路由（再次访问返回 404），避免重复安装或被恶意触发。

**重装方式**（任选其一）：
- 删除项目根目录下的 `install.lock` 文件后重新访问 `/install`
- 直接访问 `/install?force=1` 跳过 lock 校验

> Web 向导与下方 CLI 命令行为一致，二者可互换。如已通过 Web 向导完成安装，无需再执行 `php think install`。

#### 备选：命令行安装

宝塔终端执行：

```bash
cd /www/wwwroot/your-domain.com
php think install
```

安装向导会引导你完成配置，并自动执行：输入校验 → 连接预检 → 写 .env → 建库建表 → 创建管理员 → 预热缓存 → 安装后自检。


**新特性说明：**

- **输入校验**：端口非法、邮箱格式错、密码过短会提示重新输入
- **连接预检**：写 .env 前先测试 MySQL/Redis 连接，失败可重输（MySQL 重试 3 次）

- **支付可跳过**：在商户 PID 处直接回车可跳过支付配置，安装后登录后台 `/admin → 系统配置 → 支付配置` 在线补充（即时生效，无需改 .env）
- **安装后自检**：自动验证表数量(27)、Redis ping、管理员账号，输出彩色报告

**跳过 SMTP/支付的快速体验：**

```bash

# SMTP 用户名处直接回车 → 跳过邮件
# 商户 PID 处直接回车 → 跳过支付
# 安装完成后提示：邮件/支付功能未配置，后续编辑 .env
```

**--force 覆盖已有 .env：**

```bash
php think install --force
```

交互式终端会提示 `确认覆盖已存在的 .env？[y/N]`，输入 y 确认。脚本/管道调用（非 TTY）直接覆盖不询问。

> **连接失败重试**：若 MySQL 连接预检失败 3 次，安装中止。检查密码/端口/防火墙后重新执行 `php think install` 即可，不会产生残留 .env。

## 五、配置 Nginx（伪静态）

### 5.1 设置伪静态规则

进入 **网站 → 站点设置 → 伪静态**，粘贴以下规则：

```nginx
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php?s=/$1 last;
        break;
    }
}

# 静态资源缓存
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
    expires 30d;
    add_header Cache-Control "public, no-transform";
    access_log off;
}

# 禁止访问敏感文件
location ~ /\.(env|git|gitignore|htaccess) {
    deny all;
    access_log off;
    log_not_found off;
}

# 禁止访问 runtime 目录
location ^~ /runtime/ {
    deny all;
    access_log off;
    log_not_found off;
}
```

保存后，Nginx 会自动重载。

### 5.2 配置 SSL 证书

进入 **网站 → 站点设置 → SSL**：

- **方式一**：使用 **Let's Encrypt** 免费证书（推荐），点击申请，自动续签
- **方式二**：上传自有证书

启用 SSL 后，开启 **强制 HTTPS**。

### 5.3 修改 .env 启用 HTTPS

宝塔终端：

```bash
cd /www/wwwroot/your-domain.com
```

编辑 `.env` 文件，修改：

```ini
SESSION_SECURE = true
```

> 启用 HTTPS 后，Session Cookie 必须设置为 secure，防止 HTTP 明文传输被截获。

## 六、配置 Supervisor（队列消费者）

### 6.1 安装 Supervisor

宝塔终端：

```bash
# CentOS
yum install -y supervisor
systemctl enable supervisord
systemctl start supervisord

# Ubuntu/Debian
apt install -y supervisor
systemctl enable supervisor
systemctl start supervisor
```

或在 **软件商店** 搜索 "Supervisor" 安装宝塔插件。

### 6.2 创建配置文件

宝塔终端：

```bash
vim /etc/supervisord.d/pansou.ini
```

> Ubuntu/Debian 路径：`/etc/supervisor/conf.d/pansou.conf`

粘贴以下内容（替换 `/www/wwwroot/your-domain.com` 为实际路径）：

```ini
[program:pan-crawl]
command=php /www/wwwroot/your-domain.com/think crawl:consume
directory=/www/wwwroot/your-domain.com
numprocs=4
process_name=%(program_name)s_%(process_num)02d
autostart=true
autorestart=true
startsecs=3
startretries=5
user=www
redirect_stderr=true
stdout_logfile=/www/wwwroot/your-domain.com/runtime/log/supervisor-crawl.log
stdout_logfile_maxbytes=20MB
stdout_logfile_backups=5

[program:pan-mail]
command=php /www/wwwroot/your-domain.com/think mail:consume
directory=/www/wwwroot/your-domain.com
numprocs=2
process_name=%(program_name)s_%(process_num)02d
autostart=true
autorestart=true
startsecs=3
startretries=5
user=www
redirect_stderr=true
stdout_logfile=/www/wwwroot/your-domain.com/runtime/log/supervisor-mail.log
stdout_logfile_maxbytes=20MB
stdout_logfile_backups=5
```

### 6.3 启动 Supervisor

```bash
# 重新加载配置
supervisorctl reread
supervisorctl update

# 查看状态
supervisorctl status
```

预期输出：

```
pan-crawl:pan-crawl_00   RUNNING   pid 12345, uptime 0:00:05
pan-crawl:pan-crawl_01   RUNNING   pid 12346, uptime 0:00:05
pan-crawl:pan-crawl_02   RUNNING   pid 12347, uptime 0:00:05
pan-crawl:pan-crawl_03   RUNNING   pid 12348, uptime 0:00:05
pan-mail:pan-mail_00     RUNNING   pid 12349, uptime 0:00:05
pan-mail:pan-mail_01     RUNNING   pid 12350, uptime 0:00:05
```

> **如使用宝塔 Supervisor 插件**：在插件界面添加上述两个守护进程即可，无需手动编辑配置文件。

## 七、配置 Crontab（定时任务）

### 7.1 添加定时任务

进入宝塔面板 **计划任务 → 添加任务**，分别添加以下任务：

| 任务名称 | 执行周期 | 脚本内容 |
|----------|----------|----------|
| 采集任务分发 | 每分钟 | `cd /www/wwwroot/your-domain.com && php think crawl:dispatch` |
| 关闭超时订单 | 每分钟 | `cd /www/wwwroot/your-domain.com && php think order:close` |
| 广告统计聚合 | 每天 0 点 | `cd /www/wwwroot/your-domain.com && php think ad:agg` |
| 清理过期验证码 | 每小时 | `cd /www/wwwroot/your-domain.com && php think verify:clean` |

> **执行用户** 选择 `www`。

### 7.2 验证定时任务

等待 1 分钟后，查看任务日志，确认有输出且无报错。

## 八、配置 SMTP 邮件

> **两种配置方式（任选其一）**：
> - **方式一（推荐，即时生效）**：登录后台 `/admin → 系统配置 → 邮件配置`，在线填写并保存，无需重启 PHP-FPM。
> - **方式二**：编辑项目根目录 `.env` 文件 `[MAIL]` 段（改后需重启 PHP-FPM）。
>
> 配置读取优先级：后台 system_configs 表 > `.env` > 默认值。两种方式可混用，后台配置优先。

### 8.1 QQ 邮箱配置

1. 登录 QQ 邮箱 → 设置 → 账户
2. 开启 SMTP 服务，获取授权码
3. 在 `.env` 文件中配置：

```ini
[MAIL]
SMTP_HOST = smtp.qq.com
SMTP_PORT = 465
SMTP_USER = "your-email@qq.com"
SMTP_PASS = "your-auth-code"
SMTP_FROM = "your-email@qq.com"
SMTP_FROM_NAME = "网盘搜索"
SMTP_ENCRYPTION = ssl
```

### 8.2 163 邮箱配置

```ini
[MAIL]
SMTP_HOST = smtp.163.com
SMTP_PORT = 465
SMTP_USER = "your-email@163.com"
SMTP_PASS = "your-auth-code"
SMTP_FROM = "your-email@163.com"
SMTP_FROM_NAME = "网盘搜索"
SMTP_ENCRYPTION = ssl
```

### 8.3 阿里云邮件推送

```ini
[MAIL]
SMTP_HOST = smtpdm.aliyun.com
SMTP_PORT = 465
SMTP_USER = "your-username"
SMTP_PASS = "your-password"
SMTP_FROM = "noreply@your-domain.com"
SMTP_FROM_NAME = "网盘搜索"
SMTP_ENCRYPTION = ssl
```

## 九、配置彩虹易支付

> **两种配置方式（任选其一）**：
> - **方式一（推荐，即时生效）**：登录后台 `/admin → 系统配置 → 支付配置`，在线填写商户 PID/密钥/接口地址，保存即生效。
> - **方式二**：编辑项目根目录 `.env` 文件 `[PAY]` 段（改后需重启 PHP-FPM）。
>
> 配置读取优先级：后台 system_configs 表 > `.env` > 默认值。

### 9.1 获取支付参数

在彩虹易支付平台获取：
- 商户号（PID）
- 商户密钥（KEY）
- 接口地址（API URL）

### 9.2 配置 .env

```ini
[PAY]
CAIHONG_PID = "your-pid"
CAIHONG_KEY = "your-key"
CAIHONG_API = "https://your-pay-gateway.com"
NOTIFY_URL = ""
RETURN_URL = ""
```

> `NOTIFY_URL` 和 `RETURN_URL` 留空，系统会自动根据访问域名生成。如需指定，填完整 URL：
> - 异步通知：`https://your-domain.com/pay/notify`
> - 同步跳转：`https://your-domain.com/pay/return`

### 9.3 配置支付 IP 白名单（可选）

如需限制支付回调来源 IP，编辑 `.env`：

```ini
[SECURITY]
PAY_IP_WHITELIST = "1.2.3.4,5.6.7.8"
```

留空则不限制。

## 十、生产环境优化

### 10.1 关闭调试模式

编辑 `.env`：

```ini
[APP]
```

## 十二、常见问题

### Q1：搜索无结果

**原因**：MySQL FULLTEXT 索引未生效或 `ngram_token_size` 配置错误。

**解决**：
1. 确认 MySQL 配置 `ngram_token_size=2`
2. 重启 MySQL
3. 重建索引：
   ```sql
   ALTER TABLE resources DROP INDEX ft_title_intro;
   ALTER TABLE resources ADD FULLTEXT INDEX ft_title_intro (title, intro) WITH PARSER ngram;
   ```

### Q2：邮件发送失败

**原因**：SMTP 配置错误或服务器封锁 25/465 端口。

**解决**：
1. 云服务器需在安全组放行 465 端口（出站）
2. 确认 SMTP 密码为授权码，非邮箱登录密码
3. 查看 `runtime/log/mail.log` 日志

### Q3：队列任务不执行

**原因**：Supervisor 未启动或配置错误。

**解决**：
```bash
# 查看 Supervisor 状态
supervisorctl status

# 查看队列日志
tail -f /www/wwwroot/your-domain.com/runtime/log/supervisor-crawl.log

# 重启所有队列
supervisorctl restart all
```

### Q4：支付回调失败

**原因**：回调 URL 不可达或验签失败。

**解决**：
1. 确保域名已配置 SSL（支付平台要求 HTTPS 回调）
2. 检查 `.env` 中 `CAIHONG_KEY` 是否正确
3. 查看 `runtime/log/pay.log` 日志
4. 确认支付平台回调 IP 不被防火墙拦截

### Q5：后台登录提示 419

**原因**：CSRF token 校验失败，通常是缓存问题。

**解决**：
1. 清除浏览器 Cookie 和缓存
2. 清除 Redis 缓存：
   ```bash
   redis-cli -a your-password FLUSHDB
   ```
3. 重启 PHP-FPM

### Q6：500 内部服务器错误

**原因**：通常是 `.env` 配置错误或权限问题。

**解决**：
1. 查看 `runtime/log/error.log`
2. 临时开启 `DEBUG=true` 排查
3. 确认 `runtime/` 目录权限为 `775`，属主为 `www`
4. 确认 PHP 已安装 `redis` 扩展

### Q7：定时任务不执行

**原因**：Crond 服务未启动或路径错误。

**解决**：
```bash
# 检查 crond 服务
systemctl status crond
systemctl start crond
systemctl enable crond

# 查看定时任务日志
tail -f /var/log/cron
```

### Q8：内存不足

**原因**：服务器配置过低或并发过高。

**解决**：
1. 增加 PHP `memory_limit`
2. 减少 Supervisor 进程数（`numprocs`）
3. 升级服务器配置

### Q9：install 命令连接失败如何重试

**原因**：数据库或 Redis 连接预检失败。

**解决**：
1. 检查密码、端口、防火墙
2. 确认 MySQL 用户有远程/本地访问权限
3. 重新执行 `php think install`，预检失败不会产生残留 .env
4. 若需覆盖已有 .env：`php think install --force`

### Q10：install --force 注意事项

**说明**：`--force` 会覆盖已有 .env 文件。

**注意**：
- 交互式终端会提示 y/N 确认，防止误操作
- 脚本/管道调用（非 TTY）直接覆盖，不询问
- 覆盖后会重新执行建库建表（install.sql 含 DROP TABLE IF EXISTS，安全）
- 管理员账号若已存在则更新密码，不会重复创建

### Q11：安装后后台登录 419 完整解法

**原因**：CSRF token 校验失败，通常是 Redis 缓存残留旧 session。

**解决**（按顺序执行）：
```bash
# 1. 清除 Redis 当前库（会清空所有缓存，安全）
redis-cli -a your-redis-password FLUSHDB

# 2. 清除 runtime 缓存
cd /www/wwwroot/your-domain.com
php think clear --dir

# 3. 重启 PHP-FPM
/etc/init.d/php-fpm-82 reload

# 4. 清除浏览器 Cookie 和缓存后重试
```

若仍 419，检查 `.env [SECURITY] SESSION_PREFIX` 是否被修改过。

### Q12：Web 安装向导 404 怎么办

**原因**：项目已通过 `/install` 完成过安装，根目录下存在 `install.lock` 文件，系统据此自动禁用 `/install` 路由返回 404，避免重复安装或被恶意触发。

**解决**（任选其一）：
1. **删除 lock 文件**：删除项目根目录下的 `install.lock`，重新访问 `/install`
2. **强制模式**：直接访问 `/install?force=1` 跳过 lock 校验
3. **改用 CLI**：执行 `php think install`（行为与 Web 向导一致，会重新生成 `.env`）

> `install.lock` 是防止已部署实例被重新初始化的安全机制，仅在确需重装时手动清除。重装完成后会再次生成该文件。

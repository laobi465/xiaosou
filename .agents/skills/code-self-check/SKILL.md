# 代码自检技能说明

## 快速开始

使用快捷方式 `self-check` 或直接描述相关需求来触发本技能。本技能当用户需要对生成的代码进行自检、质量检查、自动核查修复时使用，覆盖硬编码、异常容错、安全、规范等维度

## 技能内容

### 生成代码完成后执行完整自检流程，逐条核查：
1. 硬编码检查：接口地址、端口、账号密码、密钥、路径、阈值、分页值等可变参数全部抽离配置/环境变量，无明文隐私写死在业务代码；区分多环境配置，敏感数据禁止明文存储。
2. 异常容错检查：数据库、接口请求、文件读写、配置加载全部增加异常捕获，参数缺失、连接失败有友好报错，不会直接崩溃。
3. 安全检查：无SQL注入、XSS、越权漏洞，密钥、凭证不打印在日志，无危险命令执行逻辑。
4. 规范检查：常量统一管理、代码无冗余重复逻辑、变量命名规范、注释清晰，资源使用后释放（数据库连接、文件流等）。
5. 边界逻辑检查：判空、极值、空列表、负数、超时场景全部处理，无隐性bug。
6. 可维护检查：修改业务参数不用改动核心源码，支持后续扩展，无写死的固定业务规则。
自检结束后主动输出核查结果，标注存在问题并自动修复代码。

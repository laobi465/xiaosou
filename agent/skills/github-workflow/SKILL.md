# GitHub工作流技能说明

## 快速开始

使用快捷方式 `github` 或直接描述相关需求来触发本技能。本技能当用户需要GitHub代码拉取更新方案、部署方案、冲突处理、回滚方案时使用，输出两套最适配的稳定方案

## 技能内容

结合当前项目技术栈、服务器部署环境，输出两套最适配、稳定的GitHub代码拉取更新方案；分别写明完整操作步骤、适用场景、优缺点、冲突处理办法、回滚方案；方案规避硬编码，命令支持配置化，同时补充生产环境安全注意事项。

# 项目初始化技能说明

## 快速开始

使用快捷方式 `init` 或直接描述相关需求来触发本技能。本技能当用户需要初始化项目、搭建项目骨架、项目脚手架时使用，针对Vue3+ThinkPHP8技术栈提供企业级工程化完整初始化方案

## 技能内容

Vue3 + ThinkPHP8 终极完整项目初始化 AI提示词（商用工程化、零硬编码、可直接上线）

请严格按照以下企业级工程化标准，一次性完成 前后端完整项目初始化搭建，包含目录结构、基础封装、权限体系、环境配置、部署方案、Git规范、自检修复，全程禁止硬编码，所有代码必须可直接运行、可直接部署、可直接迭代。

## 一、整体强制规范（全程生效）

1. 严格前后端分离架构，前后端完全解耦。
2. 严格区分 开发/测试/生产 三套环境，所有敏感配置、地址、端口、密钥全部环境变量化。
3. 全程禁止一切硬编码：URL、IP、端口、密钥、密码、路径、阈值、文案、分页数值全部抽离配置。
4. 所有代码必须自带：异常捕获、参数校验、判空容错、日志记录、防报错机制。
5. 完成代码后必须执行完整自检，自动修复隐患并输出自检报告。

## 二、后端 ThinkPHP8 完整初始化规范

1. 目录架构规范（严格分层）

- Controller：只接收请求、返回数据，禁止写业务逻辑
- Service：所有业务逻辑、流程判断、计算逻辑
- Model：数据库模型、关联、scope、软删除
- Validate：所有接口参数验证器
- Common：公共工具类、常量、辅助函数
- Middleware：中间件、权限、跨域、日志
- Config：多环境配置分离

2. 必须初始化的基础功能

1. 多环境配置分离（dev/prod），数据库、Redis、JWT、文件存储、队列全部配置化
2. 全局统一API响应封装（code/msg/data/total 标准格式）
3. 全局异常捕获中间件，统一错误输出，生产屏蔽详细报错
4. 跨域全局中间件
5. JWT 完整登录鉴权封装、刷新Token、过期机制
6. RBAC完整权限体系：用户、角色、菜单、权限节点
7. 软删除、时间自动写入、模型基类封装
8. 统一分页封装、事务封装、Redis缓存封装
9. 所有接口强制验证器校验，杜绝非法参数
10. 操作日志、登录日志记录功能
11. 初始数据库SQL：管理员账号、基础角色、基础菜单

3. 安全规范

1. 密码加密存储
2. 禁止SQL原生拼接，全部链式查询
3. 禁止敏感信息日志打印
4. 接口权限节点验证
5. 防重复提交、简单限流

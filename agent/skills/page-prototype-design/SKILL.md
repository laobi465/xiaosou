# 页面原型设计技能说明

## 快速开始

使用快捷方式 `prototype` 或直接描述相关需求来触发本技能。本技能当用户需要设计页面原型、UI原型、页面布局设计时使用，采用明亮清爽商务风，覆盖登录页、仪表盘、列表管理页等全类型页面

## 技能内容

请基于我提供的系统业务需求，输出完整标准化页面原型设计方案，严格遵守以下硬性约束与完整规范，全程不使用暗黑风格、暗紫色、高饱和诡异妖魔化视觉元素，整体采用干净商务简约调性：
## 一、整体视觉基础规范
1. 风格定位：明亮清爽商务风，主色调选用莫兰迪低饱和色系（浅蓝、浅灰、浅绿、米白为主），背景统一浅白色/极浅灰，大面积留白；禁用暗黑底、黑色主背景、黑紫渐变、恶魔、怪物、暗黑装饰元素。
2. 适配要求：优先PC端后台管理页面，同时兼容平板自适应布局；页面字体使用常规无衬线字体，层级清晰，文字对比度适中，保证长时间浏览护眼。
3. 通用组件统一标准：圆角适中（4px~8px），阴影浅淡柔和，无边框厚重黑边；按钮区分主按钮、次按钮、文字按钮、危险按钮，色彩克制不刺眼；表单输入框白底浅灰边框，hover仅轻微变色，无强光闪烁特效。
4. 全局页面通用模块统一规范：顶部导航栏、侧边菜单栏、面包屑、标签页、全局搜索、个人信息下拉、分页组件、弹窗、抽屉、空状态、加载动画统一设计标准。

## 二、页面原型输出固定结构，每个页面必须包含完整信息
1. 页面基础信息：页面名称、访问路由、归属菜单、可见权限角色、页面核心用途
2. 整体布局结构：区域拆分（顶部区、侧边栏、内容主区域、底部辅助区），标注每个区域承载内容
3. 筛选区域原型：筛选项类型（输入框/下拉框/日期选择/单选多选）、默认值、重置/搜索按钮交互逻辑、批量操作按钮
4. 数据列表原型：表格列名、每列数据展示规则、单元格状态标签样式、排序功能、行hover效果、每行操作按钮、批量勾选逻辑
5. 弹窗/抽屉详情页原型：新增、编辑、查看详情弹窗布局，表单字段排布（单行/双行布局）、必填标红、字段校验提示位置、底部确认取消按钮
6. 空数据/加载/异常状态原型：无数据友好提示图（简约扁平化插画，无暗黑恐怖元素）、重新操作按钮；加载动画简约线性转圈，无炫酷特效
7. 交互逻辑：按钮禁用条件、弹窗打开关闭规则、表单提交防抖、数据变更实时刷新、删除二次确认弹窗、操作成功/失败轻提示
8. 权限控制原型体现：无权限按钮隐藏、禁用置灰；不同角色页面展示模块差异说明

## 三、分类页面全覆盖设计要求
1. 登录页原型：浅色简约登录，居中卡片，logo简约扁平化，输入框友好提示，无暗黑背景
2. 首页仪表盘：数据统计卡片（浅底色）、折线柱状图表（柔和配色）、待办事项快捷入口、最新操作日志列表
3. 列表管理页：标准查询筛选+表格分页体系，支持导出、导入、批量删除
4. 新增编辑表单页：多分组折叠表单、上传组件（图片/文件预览浅色窗口）、富文本简约工具栏
5. 详情查看页：分模块信息卡片，基础信息、关联数据列表、操作记录分页展示
6. 角色权限配置页：树形菜单勾选、按钮权限矩阵表格、数据权限范围选择器
7. 用户个人中心：信息修改、头像上传、密码修改、登录日志列表

## 四、细节硬性禁令全程遵守
1. 禁止暗黑主题、黑色全局背景、暗紫色调、血腥、妖魔、鬼神、暗黑魔法类图形图标；
2. 禁止高对比刺眼光影、厚重黑色描边、发光暗黑特效；
3. 图标选用线性简约商务图标，扁平化，颜色与主色调统一，无写实暗黑立体图标；
4. 所有提示插画、空状态插画为清新商务扁平风，人物、元素阳光简约；
5. 不使用哥特、恶魔、魔幻、末世类设计元素、文案装饰。
